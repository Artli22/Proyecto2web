# Proyecto 2: Calculadora 

## Cómo probar el programa
1. **Instalar dependencias:**
   ```bash
   bun install
   ```
2. **Construir el proyecto:**
   ```bash
   bun run build
   ```
3. **Para desarrollo (opcional):**
   ```bash
   bun run dev
   ```
   
## Challenges implementados
- Diseño inteefaz (o bueno yo opino que si)
- Cada test que implementen, para un máximo de 25 puntos. (En total se hicieron 6 tests)
- Cada historia de Storybook que implementen, para un máximo de 25 puntos. (En total se hicieron 5 stories principales)
- Que su código sea compliant con javascript standard.
- Implementar la operación módulo.
- Manejar parte de su lógica con un hook.
- Si ninguno de sus archivos de componentes pasa de 20 líneas de código.
- Poner un title y un favicon distinto al default.
- No utilizar node ni npm como su package manager. Deben comittear su lockfile. (Se utilizo Bun, se subio el bun.lockfile como evidencia)
- Por agregar atributos básicos de accesibilidad como aria-labels o navegación por teclado.
